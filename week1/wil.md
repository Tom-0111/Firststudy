1. Git 설치와 Github 사용법
    Git을 설치한후, 폴더 생성하고 우클릭 하면 Git bash 에서 열기가 새로 생성된다. 여기에 여러가지 명령어를 입력할 수 있다.


2. 여러가지 명령어
    사용하기 전에 ctrl+s를 눌러 저장해 준다. 파일 이름 옆에 X표시가 안뜨면 저장이 안된상태이다.
    git status : git의 상태를 보여준다. 단적인 예시로 파일에 변경사항이 생기면 빨간색 글씨로 에러가 뜬다.
    git add 파일이름 : 새로 생긴 변화나 파일을 git에 추가해준다.
    git commit -m "메시지" : 아직 commit이 무슨 의미인지는 모르겠으나 메시지와 함께 git으로 전달하는것으로 추측할 수 있다.
    git push : 최종적으로 내가 만든 파일을 git에 넘겨주는 것으로 추측된다.


3. HTML
    html 파일 생성 방법
        새 파일생성 -> index.html 파일 생성 -> 느낌표 엔터 과정을 거치면 html 기본 구조가 나온다!
        이때 body 안에 내용을 입력한 후 git에 저장후, git과 연동된 Vercel로 내보내면 끝
    Markup
        가독성을 올리기 위해 문서를 구조적으로 만든다 => 목차, 큰 제목, 작은제목, 단락으로 나눈다는 의미이다.
        이때 컴퓨터는 태그를 이용한 부가적인 MarkupLanguage가 필요하다. 
        구조는 다음과 같다.
        
        &lt;tagname&gt;content&lt;tagname&gt;
        ex) 위의 배포 링크를 예시로 들어보자면 
            <h1>유지석<h1> = 첫번째 단락에 '유지석'이라는 내용이 들어간다.
            <p1>안녕하세요. 저는 26학번 컴퓨터공학과 유지석이라고 합니다.<p1> = 첫번째 단락의 내용은 
                                                                        '안녕하세요. 저는 26학번 컴퓨터공학과   유지석이라고 합니다.'라는 내용이 들어간다.
